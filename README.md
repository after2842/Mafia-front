# Mafia Frontend

React + Vite client for the Mafia game. Uses Tailwind and MUI icons.

## Prerequisites
- Node.js 18+ (recommended)
- npm (ships with Node)

## Setup
```bash
npm install
```

## Development
```bash
npm run dev
```
Vite serves at http://localhost:5173 by default.

## Production Build
```bash
npm run build
```
Build output lands in `dist/`.

## Preview Built Assets
```bash
npm run preview
```
Serves the `dist/` build locally to verify before deploying.
